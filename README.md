This is a little front end for a database of books that I've written. The data actually goes back to 1971 on a typewriter and the first computerized versions were in the early '80s. This JavaScript version created with Claude AI is mostly based on a PERL/CGI version that I did around 2000. (Tip of the hat to the late James Liu for some of the original PERL code for a contacts list.) As of this writing on 30 May 2026, almost all of the PERL functionality has been finished, but with a small fraction of my time. Even worse, from my shallow evaluations of the code I think the quality is much better than I could do. Claude writes like a fluent native speaker, whereas I'm always suffering from bleed through from other computer languages.
